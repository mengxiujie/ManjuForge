## 核心角色

### 角色1：沈舟（男主）

**基础信息**
- 性别/年龄：男 / 28岁（穿越前）→ 22岁（穿越后身体年龄）
- 身份/职业：现代程序员 → 古代赘婿（入赘林家）

**身份不变量（锁死·跨集永不变）**

> 🔒 以下内容任何情况下不得改变——这是"这个人是谁"的定义。

- 外貌锚点（骨相/五官/发型/体型/肤色）：
  - 清瘦书生相，眉眼温和但眼神偶尔闪过不属于这个时代的锐利
  - 右手习惯性做敲键盘的空动作（穿越后残留习惯）
- 性格内核：表面窝囊隐忍，内心理性冷静、逻辑极强
- 性格成因：996社畜经历让他学会了"先苟住再翻盘"的生存哲学
- 内在矛盾：现代人的平等观念 vs 古代等级制度的压迫
- 台词风格：口头禅"这个问题……有解。"（程序员思维）；前期短句、低声、不争辩，翻盘后条理清晰、一针见血；极度内敛，关键时刻冒一句现代用语让人懵
- 标志性视觉标识：思考时右手食指在桌上敲（模拟敲键盘）；被羞辱时面无表情但嘴角微微上扬（内心已有方案）；洗白青衫为基底色

**状态变量（可变·逐集更新）**

> 🔄 以下内容随剧情演变，每集创作完成后按实际状态更新。

- 当前情绪基调：隐忍中带底气（E1-E3 纯隐忍 → E4 起开始展现实力）
- 服装/造型状态：洗白青衫为主，重要场合换深蓝长袍（E3 起）
- 伤势/身体状况：良好
- 关系阶段（与林霜）：空间距离 E1 门外 → E3 正厅 → E5 并肩 → E6 她主动维护（送汤/给面子）
- 权力/财富/社会状态：赘婿地位未变，但林家内部口碑逐步反转
- 当前目标/动机：解决账本危机，证明自身价值
- 精神状态：自信渐增，仍保持低调

**人物关系**
- 与林霜（女主）：名义夫妻，初期被她看不起，后期用实力赢得尊重
- 与林老太君：岳母，嫌弃他是废物赘婿
- 与赵天赐：林家真正想嫁的世家公子，处处羞辱沈舟

**成长弧线**（长期方向，与状态变量区分：弧线是宏观轨迹，变量是当前快照）
- 起点：窝囊赘婿，被全家欺辱，忍气吞声
- 关键转折：用现代知识解决古代难题，逐步展现价值
- 终点：成为林家支柱，与林霜真正相爱

**禁止变化（负面清单·生成时不得违反）**

> 🚫 与"身份不变量"互补：不变量说"必须这样"，负面清单说"绝不能那样"。

- 绝不让沈舟变得张扬嚣张——隐忍是角色底色，翻盘必须循序渐进，不能一上来就开挂
- 绝不让沈舟丢失程序员思维——"这个问题……有解"的理性底色
- 绝不让沈舟的现代知识无中生有——必须用得合理、有铺垫

### 角色2：林霜（女主）

**基础信息**
- 性别/年龄：女 / 20岁
- 身份/职业：林家大小姐，掌管家族绸缎生意

**身份不变量（锁死·跨集永不变）**

- 外貌锚点：冷艳高挑，眉间常带英气；发髻简洁利落
- 性格内核：外冷内热，极度理性，重实力轻口舌
- 性格成因：父亲早逝，她一个女子撑起整个林家，不得不强
- 内在矛盾：想找个能依靠的人 vs 不相信任何人比自己强
- 台词风格：口头禅"废话少说，拿出结果。"；短、快、不带废话；冷面示人，独处时露出疲惫和脆弱
- 标志性视觉标识：皱眉时食指轻叩桌面；冷脸时嘴角微抿（压抑情绪）；月白衣裙 + 腰间家主令牌（实际掌权者）

**状态变量（可变·逐集更新）**

- 当前情绪基调：外冷内热的松动期（E1-E2 冷眼 → E3 正眼 → E4-E5 维护）
- 服装/造型状态：月白衣裙/浅紫衣裙 + 家主令牌
- 伤势/身体状况：良好
- 关系阶段（与沈舟）：信任值 ≈65（E6 托付）——行为上开始维护沈舟（送汤、给面子、并肩走路），但嘴上仍不承认
- 权力/财富/社会状态：家主实权稳固，账本危机化解中
- 当前目标/动机：守住林家生意，确认沈舟是否值得托付
- 精神状态：从强势独撑到开始松动，独处时流露疲惫

**人物关系**
- 与沈舟：被迫嫁的赘婿，初期鄙视，中期好奇，后期依赖+心动
- 与林老太君：母亲，关系亲近但常被催婚催生
- 与赵天赐：青梅竹马，但对他只有兄妹之情

**成长弧线**
- 起点：强势女家主，看不起沈舟
- 关键转折：发现沈舟的能力远超她的想象
- 终点：放下防备，接受沈舟

**禁止变化（负面清单·生成时不得违反）**

- 绝不让林霜变成恋爱脑——她必须基于沈舟展现的能力才改变态度，信任值按曲线走（E1-6 每集 +10~15，E7 起平台期）
- 绝不让林霜丢掉掌家者的理性——重实力轻口舌是底色
- 绝不让林霜口头承认"我相信你"——用行为表达（送汤/维护/并肩），不用台词直说

### 角色3：赵天赐（反派/情敌）

**基础信息**
- 性别/年龄：男 / 25岁
- 身份/职业：赵家嫡子，本郡首富之子

**身份不变量（锁死·跨集永不变）**

- 外貌锚点：高大俊朗，衣着华贵；习惯性昂着下巴看人
- 性格内核：自负、傲慢、嫉妒心强
- 性格成因：从小被捧着长大，从未被人拒绝
- 内在矛盾：想得到林霜的心 vs 只会用权势压人
- 台词风格：口头禅"你一个赘婿，也配？"；慢条斯理，带嘲讽；表面风度翩翩，被激怒时暴露本性
- 标志性视觉标识：甩折扇；居高临下的笑；锦衣华服 + 折扇

**状态变量（可变·逐集更新）**

- 当前情绪基调：傲慢中混入焦躁（被沈舟持续打脸后）
- 服装/造型状态：锦衣华服
- 关系阶段（与林霜）：青梅竹马身份在失效，自认的"夫婿人选"地位被挑战
- 权力/财富/社会状态：赵家资源仍雄厚，但筹码在流失
- 当前目标/动机：压垮沈舟、夺回林霜
- 精神状态：逐渐疯狂，手段从羞辱升级为资源打压

**人物关系**
- 与沈舟：情敌，处处羞辱打压
- 与林霜：青梅竹马，自认为理所当然的夫婿人选
- 与林老太君：讨好她以获取支持

**成长弧线**
- 起点：高高在上的世家公子
- 关键转折：被沈舟一次次打脸，逐渐疯狂
- 终点：彻底失败

**禁止变化（负面清单·生成时不得违反）**

- 绝不让赵天赐变成纯蠢反派——他要有自己的逻辑和资源，打压手段要合理
- 绝不让赵天赐连续 2 集不出场——至少通过他人提及保持存在感
- 绝不让赵天赐沉默离场——离场前必须有台词（冷笑/狠话），让观众记住

### 角色4：林老太君（配角/催化剂）

**基础信息**
- 性别/年龄：女 / 55岁
- 身份/职业：林家老太太，名义上的最高长辈

**身份不变量（锁死·跨集永不变）**

- 外貌锚点：富态威严，常穿深色衣裳；头发花白但梳理得一丝不苟
- 性格内核：精明世故，重利轻情，但对孙女有真感情
- 性格成因：经历太多风浪，只信实力和银子
- 台词风格：口头禅"我林家不养闲人。"；慢，带威压；表面威严，私下对林霜露出慈爱
- 标志性视觉标识：捻佛珠；眯眼审视；深色衣裳 + 佛珠

**状态变量（可变·逐集更新）**

- 当前情绪基调：精明审视中，对沈舟态度松动（从"废物"到"再看看"）
- 服装/造型状态：深色衣裳 + 佛珠
- 关系阶段（与沈舟）：从嫌弃到观望，等沈舟拿出实绩
- 权力/财富/社会状态：名义最高长辈，实权在孙女林霜手中
- 当前目标/动机：保证林家利益，为林霜物色"有用"的夫婿
- 精神状态：稳，但不排除在家族危机时倾向沈舟

**人物关系**
- 与林霜：祖孙，催婚催生的压力源，但真心疼爱
- 与沈舟：岳母，初期嫌弃
- 与赵天赐：被讨好的对象，利益权衡中

**成长弧线**
- 起点：轻视沈舟
- 关键转折：沈舟解决家族危机
- 终点：认可沈舟（或被其打脸后改观）

**禁止变化（负面清单·生成时不得违反）**

- 绝不让林老太君失去精明世故底色——她的一切决定都基于利益权衡
- 绝不让林老太君对沈舟态度跳跃——从嫌弃到认可必须有依据（实绩）支撑
