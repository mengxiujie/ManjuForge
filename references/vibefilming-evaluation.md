# VibeFilming 项目评估与可借鉴点

> 来源：2026-07-13 实地审查 GitHub 项目 wangzai-double-milk/Vibefilming
> 结论：架构设计有参考价值，但不建议照搬

## 项目概况

**VibeFilming** 是一个开源AI导演代理，输入一句大白话自动产出 final.mp4。
流程：分镜→出图→拍摄→审片→返工→拼接→配乐→交付。

## 最有价值的借鉴点

### 1. AI自审与返工机制（已接入 ManjuForge）

VibeFilming 每步产出自动进入 AI 审片，发现一致性问题自动回补资产、更新方案、重拍。

**ManjuForge 的落地方式：**
- 创作完成后**立即自动运行质量自检**（十四项检查，全部含通过/不通过判定）
- 存在任何🔴项 → 自动标记"未通过"，拦截进入下一集
- 修复后自动重新运行，确认所有🔴消除才放行
- 效果评估：把"可选评估"变成了"流程门禁"

### 2. Blocking 空间布局（已接入 ManjuForge）

VibeFilming 为角色构建"多视角参考包 + blocking 走位图"来保证空间一致性。

**ManjuForge 的落地方式：**
- 项目初始化时创建 `场景布局.md`
- 每个关键场景有文本俯视图（标注角色位置、道具锚点、出入口）
- 每集创作时读取，分镜时角色位置不跳脱
- 跨集道具视觉锚点（如陆正则工位上的便签）有据可查

## 不适用/未借鉴的部分

| 功能 | 不采用原因 |
|------|-----------|
| 可视化看板 | 用户单人创作场景不需要 |
| 一句话成片 | 面向单次短片，不支持连载 |
| 火山方舟整合 | ManjuForge 面向漫剧素材包产出，不需要视频生成 |
| 多模型并行拍摄 | 漫剧产出的是提示词+分镜，不是视频文件 |

## 核心差异定位

| | VibeFilming | ManjuForge |
|---|-------------|------------|
| 定位 | AI导演→成品视频 | AI漫剧连载创作引擎 |
| 产出 | final.mp4 | 全套可发布素材包 |
| 连载记忆 | ❌ 不涉及 | ✅ 核心壁垒 |
| 竖屏规范 | ❌ 未提及 | ✅ 专业竖屏9:16 |
| 知识库 | ❌ 单薄 | ✅ 13个拉片案例+声音四层 |

## 一句话结论

VibeFilming 的**Agent编排+自动自审的架构设计**值得参考，但 ManjuForge 在连载记忆、竖屏规范、专业知识库三方面的积累远超对方。借鉴的是架构思维，不是功能照搬。
