# 优酷动漫“天作”计划2026运行时专项补丁

> 生效：2026-08-25  
> 官方信息日期：2026-07-30  
> 适用：`platform=优酷动漫天作计划`，尤其《山海：我以微尘填沧海》  
> 优先级：高于 `platform_adaptation.md` 与 `shanhai_landscape_epic_mode.md` 中旧时长示例；低于用户当次明确要求与项目canon

## 一、官方最低门槛

- 画幅：横屏；
- 单集：≥10分钟；
- 集数：≥10集；
- 全季总时长：≥150分钟；
- 投稿内容：节目名、全集大纲、5集剧本、1集对应样片（≥5分钟）、主创信息；
- 投稿邮箱：`ykdmnrhz@list.alibaba-inc.com`。

官方公开来源：

- 优酷动漫认证官方微博公开征稿镜像：`https://www.sina.cn/news/detail/5326357850229876.html`
- 优酷内容合作平台：`https://om.youku.com/`

## 二、解释纪律

1. “单集≥10分钟”与“集数≥10集”都是下限，不得解释为恰好10分钟或恰好10集。
2. 若采用10集，全季均集必须≥15分钟；若采用14集，均集必须≥10分43秒；若采用15集，均集必须≥10分钟。
3. 固定OP、ED、平台广告、下集重复回顾与花絮不得预先计入有效剧情时长。平台商务另有书面确认时再单列。
4. “样片≥5分钟”是公开最低门槛，不等于必须25分钟。更长样片属于项目自主策略。

## 三、《山海》锁定执行参数

```yaml
platform: 优酷动漫天作计划
format: landscape_16_9
episode_count: 14
season_runtime_target: 152m00s
episode_minimum: 10m00s
episode_target_band: 10m40s-11m00s
sample_public_minimum: 5m00s
source_master: 07_十集统稿
output_version: 08_十四集平台版_v1.0
```

选择14集而非15集的理由：现有十集后半段四个高密度集可自然拆成八集，新增集数全部来自已经成立的因果链；不需要新角色、新反派、新任务或支线。旧14集稿只提供“14集容量可行”的历史证据，不提供canon与正文。

## 四、反注水检查

新增或延长的场景必须至少承担下列两项：

- 改变角色可选择的路径；
- 显示上一集不可逆代价仍在；
- 建立下一次选择所需的动作因果；
- 让奇观后的具体生命后果可见；
- 完成跨集物件、声音、材质或空间呼应；
- 让群体承担自己的部分，但不替精卫授权意义。

仅增加空镜、慢动作、重复闪回、解释性台词、战斗轮次、群众欢呼或预告回顾，均判定为无效时长。

## 五、判废条件

- 任一集正片低于10分钟；
- 全季正片低于150分钟；
- 依靠片头片尾或重复内容才达到门槛；
- 为扩时复活国运值、系统任务、蓐收裁决、鲲祖对白、公众呼名或身份恢复授权；
- 直接复制E盘旧14集稿正文。
