# 《山海》横屏神话史诗专项模式

> 适用项目：`《山海：我以微尘填沧海》`
>
> 模式标识：`shanhai_landscape_epic`
>
> 画幅与时长：16:9 横屏；单集不得低于10分钟；全季不得低于150分钟
>
> **2026-08-25运行时覆盖**：本项目采用14集/目标152:00平台版。原“9.5—11分钟/集”中的9.5分钟下限停止使用；不得以片头、片尾、预告或重复镜头替代有效剧情时长。具体依据见 `tianzuo_2026_runtime_patch.md`。

## 一、模式定位与优先级

本文件是 ManjuForge 面向《山海》的专项覆盖层，不重写通用 Skill，也不替代项目任务书、创作大纲、设定集、既有定稿剧本或 canon。

启用本模式后，规则优先级为：

1. 用户当次明确要求；
2. 《山海》项目任务书、canon、禁用词与定稿设定；
3. 本专项模式；
4. `platform_adaptation.md` 的 landscape 通用规则；
5. ManjuForge `SKILL.md` 的默认规则。

若低优先级规则与本文件冲突，以本文件为准。ManjuForge 的七文件记忆、Story Bible、Character Graph、Foreshadow Engine、角色与视觉一致性检查继续生效。

## 二、创作北极星

《山海》不是“神鸟打败大海”的胜负故事，而是“一个孩子慢慢成为一座保护世界的山”的选择故事。

全剧唯一主题母题是：**回应权**。

“回应权”指：世界可以夺走人的身体、故乡、姓名与记忆，但不能替她决定如何回应失去。精卫填海不是对海洋的报复，也不是靠意志喊出口号，而是在明知无法恢复旧日生活之后，仍选择为后来者留下可以继续生活的土地。

执行要求：

- 主题必须通过选择、动作、代价、物件、声音和环境变化呈现；
- 精卫不主动解释自己的崇高，不用宣言替代行动；
- 每集最多保留一句直接触碰主题的台词，且能删则删；
- “胜利”不作为爽点处理，完成使命必须同时意味着不可挽回的失去；
- 精卫始终保留幼女的感知、依恋、迟疑和倔强，不写成借幼女外形说成人大道理的符号。

## 三、平台规则覆盖

### 3.1 禁止互动引导

成片剧本、分镜、配音文案和片尾中禁止出现任何平台互动话术，包括但不限于：

- “评论区告诉我”；
- “点赞、关注、转发”；
- “如果是你会怎么选”；
- 面向观众的二选一、投票、催更或关注暗示。

集尾只允许使用剧情内悬念、情绪截断、意象回响或下集预告。

### 3.2 禁止抖音式标题党

每集采用 `EP序号 + 集名` 的作品化命名。标题可以有诗性、事件性或命运感，但不得使用夸张口语、营销悬念句、结果剧透、群体情绪夸大或未在本集兑现的噱头。

允许：`EP6 天柱裂隙`、`EP10 微尘不息`。

禁止：`她做出这个选择后，所有神都沉默了`、`父亲一句话让精卫彻底崩溃`。

### 3.3 不要求反派必须说话

取消“反派离场前必须有台词”“反派必须用狠话维持存在感”等默认要求。

鲲祖、归墟及其压力可以通过尺度、遮蔽、潮汐、吞没、失声、空间异变和角色反应建立。沉默不是张力缺失；在本项目中，沉默本身就是威胁机制。

只有当台词揭示角色意志、改变关系或推动选择时才保留。不得为了满足反派存在感而追加解释、嘲讽或预告式狠话。

### 3.4 不要求 3 秒强钩子

取消“前 1 秒制造信息缺口”“前 3 秒必须强刺激”“第一帧必须承担短视频防划走任务”等抖音式硬约束。

开篇仍需有效，但允许使用海天、遗迹、呼吸、器物、静默或缓慢运动建立世界与情绪。前 30 秒应完成以下两项中的至少一项，最好兼具：

- 建立本集独有的世界状态或视觉命题；
- 让观众感到精卫当下正在失去、守护或无法回答的东西。

开篇是否成立，以“是否建立观看期待与情绪方向”判断，不以剪辑速度判断。

## 四、10—11 分钟横屏基础节奏

每集目标时长约 10:40—11:00，任何一集不得低于10:00；全季目标152:00。采用长短镜头交替的横屏番剧节奏。以下为功能区间，不是机械卡点：

| 时段 | 叙事功能 | 节奏要求 |
|---|---|---|
| 0:00—0:45 | 世界状态与第一情绪点 | 可慢入；先建立观看关系 |
| 0:45—2:30 | 本集问题出现 | 冲突必须具体落到人物、物件或空间 |
| 2:30—5:30 | 尝试、阻力与关系变化 | 允许留白；避免连续解释设定 |
| 5:30—7:45 | 选择逼近、奇观升级 | 奇观必须服务于选择和代价 |
| 7:45—9:30 | 结果与情绪沉降 | 必须让代价被看见、被听见或被触摸 |
| 9:30—10:00 | 意象回响、钩子或预告 | 不做互动引导，不用标题党收尾 |

执行原则：

- 平均镜头/叙事碎片可参考 10—20 秒，但不机械切割；
- 关键凝视、记忆消退和父女情绪允许更长镜头；
- 动作高潮可短切，高潮后的情绪镜头必须留足时间；
- 每集应有自己的节奏性格，禁止五集套用同一冲突—反转—爆点模板。

## 五、强制不可逆代价表

每集在场景骨架完成后、正文开写前，必须填写本集不可逆代价。没有真实代价，不得进入全文创作。

### 5.1 通用模板

| 字段 | 必填内容 |
|---|---|
| 本集主动选择 | 精卫或关键角色主动做了什么 |
| 即时代价 | 当集可见、可感的损失 |
| 不可逆部分 | 后续无法恢复、撤销或用新能力抵消的部分 |
| 视觉/声音载体 | 用哪个物件、动作、色彩或声音让代价落地 |
| 跨集后果 | 下一集以后如何持续改变人物或世界 |
| 防伪检查 | 若删掉该代价，本集是否几乎不变；若是，则代价无效，必须重设 |

不可逆代价不得仅写成受伤、疲惫、法力消耗或暂时失败。它必须改变人物还能拥有什么、记得什么、返回哪里、以何种身份存在，或与谁保持原有关系。

### 5.2 EP6—EP10 锁定方向

下表锁定“代价的性质”，具体场面可创作，但不得降级为短暂困难：

| 集数 | 不可逆代价方向 |
|---|---|
| EP6 | 精卫接受众生的支撑，也失去独自停下、独自返回的权利；她的选择开始成为共同命运。 |
| EP7 | 她逐渐记不起“家”的具体模样，只剩下“要保护什么”的身体记忆。 |
| EP8 | 她失去最后一次完整回到“女娃”身份与父亲身边的可能。 |
| EP9 | 她放弃个体形态，化入山海；消散前短暂记起自己是谁，使牺牲具有清醒性。 |
| EP10 | 后世无法准确记住她完整的姓名、面容与经历，但她作出的回应被文明继承。 |

每集自检必须回答：上一集代价是否仍然存在？本集是否在其上继续累积，而非悄然恢复？

## 六、强制“奇观后静镜头”

每次大型奇观、战斗爆发、神力释放、空间崩塌或群体高呼之后，必须安排至少一个静镜头或低运动镜头，使观众看见奇观对一个具体生命造成了什么。

静镜头可使用：

- 精卫指尖、呼吸、瞳孔、伤口或空下来的手；
- 木簪的裂纹、黯淡、拔出或余光；
- 被潮水浸湿的器物、空屋、脚印、羽毛或无主衣物；
- 风停后的环境声、远处鸟鸣、短暂失声或未被回答的呼唤；
- 炎帝没有说出口的话，以及人物之间无法跨越的距离。

执行标准：

- 静镜头通常保留 5—10 秒，可按情绪需要延长；
- 不用旁白解释刚刚发生的意义；
- 不用配乐把情绪推满，优先让环境声、呼吸或短暂静默承担余震；
- 若删除静镜头只损失时长、不损失人物代价，则该静镜头无效，应重写。

## 七、鲲祖与归墟：“无回应世界”

鲲祖与归墟不是普通怪兽反派，也不是等待主角辩论、感化或击败的拟人化敌人。它们共同代表一个“不回应人的痛苦，也不承认人的意义”的世界机制。

### 7.1 表现原则

- 归墟吞没光、声音、方向、名字和因果，不主动解释自身；
- 鲲祖更接近归墟压力的形体、尺度或古老意志，不承担话痨反派功能；
- 威胁优先通过环境规则改变呈现：呼喊没有回声、火光照不远、道路回到原点、名字从记忆中脱落、巨物移动却几乎无声；
- 允许鲲祖沉默到底。若开口，语言应稀少、非说明性，并强化“回应不会得到回报”的压迫感；
- 不把终局写成“杀死鲲祖/打爆归墟即解决一切”。精卫真正完成的是：在无回应的世界面前，仍建立人自己的回应。

### 7.2 禁止写法

- 用长篇台词讲解归墟起源、阴谋与战斗规则；
- 用嘲讽、威胁、狂笑把鲲祖降格为常规反派；
- 让归墟因精卫的口号而愤怒、动摇或认输；
- 把填海简化为复仇成功、战力升级或单纯封印怪物；
- 用“正义战胜邪恶”替代“人在无回应中仍选择回应”。

## 八、单集执行清单

每集创作与修订时逐项确认：

- [ ] 使用16:9横屏；本集≥10:00；全季规划≥150:00；
- [ ] 无评论、点赞、关注、投票等互动引导；
- [ ] 集名为作品化命名，无标题党或未兑现噱头；
- [ ] 未强行设置 3 秒刺激钩子，前 30 秒已建立世界状态或情绪方向；
- [ ] 未为满足规则而给鲲祖/归墟追加台词；
- [ ] 已填写不可逆代价表，且代价不能在后续被便利恢复；
- [ ] 每个大型奇观后都有有效静镜头；
- [ ] “回应权”通过人物选择与损失呈现，而非口号解释；
- [ ] 鲲祖/归墟保持“无回应世界”的叙事功能；
- [ ] 木簪、赤羽、息壤、冥火等视觉锚点与项目 canon 一致；
- [ ] 通用记忆文件、伏笔状态和跨集人物状态已同步。

## 九、最终判废条件

出现下列任一情况，本集不得通过专项模式验收：

1. 出现互动或关注引导；
2. 使用抖音式标题党或标题内容未兑现；
3. 为让反派“有存在感”而强加解释性台词；
4. 用前三秒快切、喊叫或突发攻击替代有效开篇；
5. 未建立不可逆代价，或代价可被轻易恢复；
6. 大型奇观后立即进入下一次信息/动作刺激，没有情绪沉降；
7. 用宣言直接解释“回应权”；
8. 将鲲祖/归墟写成常规可击败、可说服、可互骂的反派；
9. 为追求宏大而丢失精卫作为孩子的具体感受。
