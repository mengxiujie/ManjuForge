# 平台适配层（Platform Adaptation）

> 2026-08-24 新增。ManjuForge 原规则按"抖音竖屏短剧"硬编码（互动引导/关注引导/3-5分钟时长/标题悬念句）。
> 《山海》C线是优酷天作计划（横屏10分钟番剧·评审制），规则错配会带偏生产。
> 本文件把平台相关规则参数化，创作前先锁定 `platform` 参数，再套用对应规则。

> **2026-08-25官方口径纠偏（最高优先级）**：优酷动漫2026-07-30公开征稿要求为横屏、单集≥10分钟、集数≥10集、总时长≥150分钟，1集对应样片≥5分钟。下文凡写“10分钟”均解释为最低值而非固定值；凡写“10集”均解释为最低集数而非固定集数。详见 `tianzuo_2026_runtime_patch.md`。

## 二、创作前锁定

阶段一初始化时**必须**确认目标平台，写入项目记忆（建议存世界观.md 或单独 platform.md）：

```markdown
platform: 优酷横屏番剧（天作计划）
format: landscape
单集时长: ≥10分钟
总集数: ≥10集
总时长: ≥150分钟
碎片时长: 平均10-20秒
标题: 节目名《山海：我以微尘填沧海》+ Slogan（以一族之灭，换文明之生；以一鸟之躯，填天地之漏）
结尾: 悬念截断+下集预告字幕卡（无"评论区告诉我"类引导）
```

锁定后所有集数生成、分镜、自检按该平台参数执行，**禁止混用平台规则**。

## 三、优酷横屏番剧专项规则（landscape）

### 标题/节目名
- 节目名即品牌：`《山海：我以微尘填沧海》` 主标题+副标题结构
- 每集标题可用悬念句（EP1溺海·烬余/EP2烈火渊·微光初燃），但**必须在本集兑现**——标题欺诈规则同样适用

### 开篇
- 前30秒：建立世界观氛围（海天/归墟）+ 第一情绪锚点（精卫追蝶/溺水），无需3秒强钩子
- 评审会看完样片，但前30秒决定评委的"第一印象分"——技术应用/视听效果两个维度的第一证据

### 结尾
- 悬念截断（竖屏同规则）✓
- 下集预告：EP结尾字幕卡或10-15秒预告片段（25分钟样片方案里第1集结尾+第2集连播即此逻辑）
- ❌ 不写"评论区告诉我""点赞关注"类引导——评审制无此需求，且伤番剧质感

### 集级节奏（10—11分钟基础单元）
```
0:00-0:30   世界观建立/钩子
0:30-2:30   冲突建立（第一情绪点）
2:30-5:00   发展/铺垫（留白+环境叙事）
5:00-7:30   转折/高潮（特效展示点）
7:30-9:30   收束/情绪沉降
9:30-10:00  悬念截断+预告
```
> 具体按分镜 skill 的横屏AI执行版执行；此为平台节奏参考，不是硬模板。

### 合规（天作四维之一）
- 公版IP（精卫填海）零风险 ✓
- 双男主/情感向淡化审计：本作无此问题（父女+神话史诗）
- 暴力/死亡画面：溺水/搏斗等按平台内容审核口径处理（避免过度血腥特写）

## 四、规则迁移对照（抖音规则 → 优酷横屏）

| 抖音规则（原SKILL.md） | 优酷横屏处理 |
|------------------------|-------------|
| 互动引导（评论区告诉我） | **删除**——评审制不需要 |
| 关注引导（悬念句） | **替换**为下集预告字幕卡 |
| 时长3-5分钟 | 10分钟（横屏番剧） |
| 标题悬念句+兑现 | 保留兑现规则；标题结构改为节目名+集名 |
| 前3秒视觉钩子 | 放宽为前30秒世界观+情绪点 |
| 碎片3-7秒 | 10-20秒（landscape） |
| 字幕卡（角色首次出场） | **保留**——评审看角色识别，字幕卡帮评委快速建立角色锚点 |
| 视觉锤镜头 | **保留且强化**——这是"视听效果"维度的直接证据，每集≥2个 |
